# ByteSized AI pipeline

Script → LoRA v3 scenes on Kaggle GPU → edit → upload to YouTube.

| Step | Command |
|---|---|
| Voiceover (Edge-TTS, paced per sentence) | `python pipeline/tts.py en-US-BrianNeural` (edit `SEG` list) |
| Music (original, procedural) | `python pipeline/music.py` |
| Scenes (SDXL + Quill Daily LoRA v3 on Kaggle T4) | `python pipeline/gen_scenes.py projects/<name>/shots.json --format short` |
| Edit / assemble | `python pipeline/assemble.py projects/<name>` |
| Thumbnail (long-form) | `python pipeline/thumbnail.py img.png thumb.jpg --text "LINE 1\|LINE 2"` |
| Upload (private by default) | `python pipeline/upload_youtube.py video.mp4 --meta projects/<name>/upload.json` |

## Notes
- **Prompts must stay under 77 CLIP tokens.** Scene description goes first, short style trigger last. The Kaggle log prints a token count per shot.
- Kaggle auth: `tools/kaggle_cli.py` (token is injected by the session proxy).
- YouTube auth: env vars `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`.
- Every upload is private (or scheduled with `--publish-at`) so a human reviews it first.

## Description guidelines (every upload)
Generated by `pipeline/describe.py` from the `meta` block in `script.json`:
hook line → 2–3 sentence summary → "In this video" bullets → chapters with timestamps (long-form) →
sources → subscribe line → AI-art disclosure → 3–5 hashtags. Never keyword-stuff.

## Series format (from video 3 on)
- Every video is a continuous story with the recurring cast in `characters.json` (Byte, Nova, Boss, Gramps), not unrelated one-off scenes.
- The script is written as scenes: each line names who is on screen and where, and the shot prompt uses the character's fixed descriptor.
- Locations repeat as "sets" (Byte's living room, Boss's office, and so on) so cuts feel like one movie.
- The LoRA can't guarantee identical faces, so identity comes from fixed colours and props. During curation, drop any variant where a character's colours are wrong.
- Long-form: white captions (`caption_style` in edit.json); number callouts sit above the captions.
- Scenes the LoRA can't draw well may be replaced with hand-drawn SVG art in `art/`. Example: `art/g002_custom.py`.

### Qwen-Image-Edit on Kaggle T4 x2: notes
- Budget: plan_qshots now defaults to --max-hold 3.2 (fewer images per video). Works in bf16: about 295 s/image at 1024x576 with the 8-step Lightning LoRA. The transformer is split over both GPUs, attention is query-sliced, and VAE tiling is on.
- `--dtype fp16` gives black frames (NaN). `--dtype mixed` (fp16 matmuls, fp32 residual, scaled projections) runs at 125 s/image without NaNs, but the output is noise. **Don't use it**; budget around 5 min/image instead.
